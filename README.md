# Multiple File Date Time Editor

Windows 로컬 도구로, 여러 파일의 만든 날짜와 수정한 날짜를 시간표 순서대로 배정합니다. 파일 자체는 업로드되지 않습니다.

## 실행

1. `start-windows.cmd`를 더블 클릭합니다.
2. 저장된 시간표 1~4 중 하나를 고르고 시각 후보를 입력합니다. 연·월·일은 공통 배정 날짜에서 지정합니다. 파일을 불러오면 파일 이름에 유효한 날짜가 있을 때 그 날짜를 우선 사용하고, 없을 때만 파일의 만든/수정 날짜를 사용해 최빈 날짜를 자동 선택합니다. 날짜는 직접 바꿀 수도 있습니다.
3. 파일을 선택하거나 데스크톱 창에 여러 파일을 끌어 놓습니다. 드롭 영역에 놓으면 목록 끝에 추가되고, 특정 행에 놓으면 그 행 앞에 삽입됩니다. 각 행에서 파일 삽입, 위/아래 이동, 목록에서 제거도 할 수 있습니다.
4. 배정 미리보기를 확인합니다. 원본 차이/용량별 평균을 반영한 기준 간격 이하인 후보 시각은 건너뜁니다.
5. 지원되는 영상 파일은 목록의 **재생** 버튼으로 미리 볼 수 있습니다. TS/M2TS는 FFmpeg가 H.264/AAC MP4로 변환해 로컬 스트리밍합니다. 변환 중 CPU를 사용하며 첫 재생이 늦을 수 있고, 재생 위치 탐색은 제한됩니다.
6. 필요하면 미리보기에서 만든/수정 시각을 직접 고칩니다. 수정한 시각은 기준점이 되고, 그 다음 이벤트부터 다시 자동 배정됩니다.
7. 결과가 맞으면 **파일 날짜 변경**을 누릅니다.

기본 시간표는 50개 입력란으로 시작하며 **입력란 추가**로 늘릴 수 있습니다. 입력 즉시 시간표 세트와 마지막 배정 날짜를 브라우저의 로컬 저장소에 자동 저장합니다. 시간표 이름을 바꾸거나 복제·삭제할 수 있으며 마지막 남은 세트는 삭제할 수 없습니다. 파일 이름의 날짜를 우선 반영한 뒤 여러 날짜가 같은 횟수로 가장 많이 나온 경우 첫 파일의 날짜를 우선합니다.

시간표의 시(hour)를 바꾸면 같은 시 차이만큼 뒤 슬롯도 이동합니다. 자정을 넘어야 하는 경우에는 오전/오후를 순환시켜 잘못된 시간을 만들지 않도록 해당 슬롯들과 그 이후는 그대로 둡니다.

## 간격 모델

2025년 자료를 중심으로 여러 Edited 폴더의 `.ts` 파일 메타데이터를 분석했습니다. 2025년 날짜가 파일명에 들어간 표본 8,587개를 크기 순서로 10개 비슷한 크기 그룹으로 나누고, 각 그룹에서 중앙값 + 4.4478 × MAD보다 큰 간격을 이상치로 제외한 뒤 평균을 계산했습니다. 생성 시각보다 수정 시각이 빠른 표본 2개는 제외했습니다.

미리보기는 파일 용량별 모델 평균과 선택한 파일 자체의 원본 생성/수정 차이를 함께 표시합니다. 원본 차이가 0 이하이거나 모델 평균의 1.5배를 넘으면 모델 평균을 기준으로 하고, 그 외에는 원본 차이를 기준으로 합니다. 따라서 큰 파일도 우선 실제 메타데이터 간격을 따르며, 평균보다 지나치게 긴 간격은 평균값으로 제한합니다.

재생은 파일을 업로드하거나 변환 파일을 디스크에 저장하지 않고 로컬 서버에서 처리·스트리밍합니다. TS 미리보기는 `ffmpeg-static`에 포함된 FFmpeg 실행 파일을 사용합니다. 이 실행 파일의 라이선스는 GPL-3.0-or-later이므로 앱을 배포할 때는 라이선스 조건을 확인하세요.

## 참고

- 파일 선택과 만든 날짜 변경은 Windows에서 지원합니다.
- 만든 날짜는 Windows 파일 API로 변경합니다. 파일 권한, 잠금, 파일 시스템에 따라 일부 변경이 실패할 수 있습니다.
- 별도 로컬 서버 포트 `3102`를 사용하므로 File Date Tool 및 Frame Capture 서버와 동시에 사용할 수 있습니다.
- `start-windows.cmd`로 실행하는 Electron 창에서 파일 드래그 앤 드롭이 가능합니다.
